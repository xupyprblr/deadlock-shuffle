# Арт для режима «Крутить билд»: задача для Claude Code

Сейчас слот-машина и лутбокс на https://randomlock.com/dev/slots.html нарисованы на CSS (`public/css/slots.css`,
разметка в `stage()` в `public/js/slots.js`). Цель: заменить их на нарисованный арт в духе игрового автомата
Sinner's Sacrifice из Deadlock, но **оригинальный**, не копию.

Промты подготовлены в облачном чате «Слот-крутка билдов в Dev» (13.11.2026) и лежат в `prompts/`.
Генерация идёт через плагин OpenAI (GPT) в Claude Code, Алекс контролирует результат.

## Порядок работы

1. **Референсы.** Алекс кладёт в `refs/` скриншоты автомата **из самой игры**. Фан-арт (например, работы medikkuu)
   в референсы не давать: это чужая коммерческая работа. Референс задаёт только настроение, не дизайн.
2. **Корпус первым.** Сгенерируй `prompts/01-cabinet.txt` с референсами из `refs/`. Сделай 2–4 варианта,
   сохрани в `raw/01-cabinet-v1.png`, `v2`…, покажи Алексу и проверь по чек-листу ниже. Дальше идём только с корпусом,
   который выбрал Алекс.
3. **Остальное в том же стиле.** `02-lever`, `03-lootbox`, `04-symbols`, `05-card-back` генерируй, передавая
   **выбранный корпус как референс** (image input / edit), чтобы стиль совпал. Промты начинаются с «Same art style»
   и без референса не работают.
4. **Правки.** Точечно через `prompts/99-edit.txt` (подставить, что поменять), с исходной картинкой на входе.
5. **Подготовка ассетов** (см. ниже) → **вёрстка** (см. ниже) → проверка Алексом на localhost → push в `dev`.

Если плагин умеет параметры, ставь: размер корпуса 1024×1536 (портрет 2:3), остальное от 1024 по длинной стороне,
`background: transparent`, максимальное качество.

## Чек-лист качества (проверять каждую картинку, прежде чем показывать Алексу)

- **Окна барабанов пустые**, ровные прямоугольники, залиты чёрным, три одинаковых. Если внутри что-то нарисовано,
  перегенерировать с добавкой `the reel openings must stay empty flat black rectangles`.
- **Строго фронтальный вид**, без перспективы и ракурса три четверти. В перекошенные окна барабаны не вставить.
- **Симметрия**, автомат целиком в кадре с полями, без тени на «полу».
- **Фон прозрачный.** Если вышел белый или клетчатый (нарисованная «прозрачность»), перегенерировать с
  `solid pure magenta #ff00ff background` и вырезать фон скриптом.
- **Табло под окнами пустое**: туда кодом выводится «LEGENDARY / JACKPOT».
- **Надписи без ошибок** («BUILD SLOTS», «SPIN TO WIN», «PRAY FOR GOLD»). Если буквы кривые, вывеска без текста
  (`blank sign face`), текст накладываем шрифтом сайта (Rubik 900 / Alegreya 800).
- **Нет чужого:** логотипов Valve/Deadlock, копий надписей и компоновки игрового автомата, водяных знаков.
- **Палитра сайта:** оранжевый `#dd6638`, бирюза `#60cde3`, жёлтый `#ffe14d`, кремовый `#f7e9d5`, угольный `#100e0e`.
- **Рычаг** на корпусе нарисован в верхнем положении. Отдельный спрайт рычага (02) должен совпадать по форме,
  чтобы анимировать его поверх корпуса.
- **Символы (04):** 9 плиток одного размера, без текста (кроме «777»), читаются в размере 48 px.

## Подготовка ассетов

- Исходники генерации: `slot_machine/raw/` (в git не попадают, см. `.gitignore`).
- Готовые файлы: `public/img/slots/` в **WebP** (качество ~85), обрезка по содержимому, прозрачный фон:
  - `cabinet.webp` (ширина ~900 px, плюс `cabinet@2x.webp`, если не слишком тяжело);
  - `lever-up.webp`, `lever-down.webp` (разрезать лист 02);
  - `crate-closed.webp`, `crate-open.webp`, `crate-lid.webp` (разрезать лист 03);
  - `sym-weapon.webp`, `sym-spirit.webp`, `sym-vitality.webp`, `rar-trash.webp`, `rar-common.webp`,
    `rar-unique.webp`, `rar-rare.webp`, `rar-ultra.webp`, `rar-legendary.webp` (разрезать лист 04, по ~160 px);
  - `card-back.webp`.
- Бюджет: всё вместе до ~600 КБ. Страница должна грузиться быстро и с телефона.

## Вёрстка (после того, как Алекс принял арт)

Соответствие кода и арта:

| Сейчас (CSS) | Станет |
|---|---|
| `.sm`, `.sm-top` (лампочки, «Build Slots»), рамка `.sm-reels` | `cabinet.webp` фоном/подложкой |
| `.reel` ×3 | позиционируются **поверх пустых окон корпуса** в процентах от размера картинки (замерить окна на итоговом файле) |
| `.sm-lever` (`.lv-arm`, `.lv-ball`) | спрайт `lever-up` / `lever-down`, анимация `.pull` остаётся |
| `.sm-plate` | поверх пустого табло корпуса |
| `.lb-box`, `.lb-lid`, `.lb-body` | `crate-closed` / `crate-open` / `crate-lid`, текущие состояния `idle / shake / burst / open` сохраняются |
| рубашка карточек в `.lb-cards` | `card-back.webp` |
| `invCell` / `rarCell` в барабанах | символы `sym-*` и `rar-*` |

Что нельзя потерять:
- эффекты по редкости (`data-rar`, `--rc`): Trash сереет и проседает, Rare искры, Legendary JACKPOT, монеты, тряска;
  мигание лампочек можно сделать светящимися точками поверх нарисованных ламп;
- `prefers-reduced-motion` (без анимаций, результат сразу);
- телефон: автомат масштабируется по ширине, окна барабанов остаются на месте (всё в процентах);
- светлая тема: арт сам по себе, проверить, что он не теряется на светлом фоне;
- RU/EN подписи, клавиша пробел, кнопка «Крутить билд»;
- CSP: картинки локальные (`img-src 'self'`), новых внешних адресов не добавлять.

Проверка: `node scripts/test.mjs`, `npm run dev` → http://localhost:5173/slots.html на ПК и в узком окне,
скриншоты Алексу. После «да» коммит в `dev` (`Крутить билд: нарисованный автомат и лутбокс`) и push.
