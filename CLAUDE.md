# RANDOMLOCK (deadlock-shuffle): инструкция для Claude Code

> Владелец: Алекс (канал **podvalni akrobat**). Общение **на русском**, тон прямой и практичный, без воды.
> Работа идёт с Windows: VS Code + расширение Claude Code, терминал PowerShell.

---

## 1. Что за проект

**RANDOMLOCK by podvalni akrobat**, https://randomlock.com: рандомайзер для игры Deadlock.
Выдаёт случайного героя, 12 предметов с порядком покупки, порядок прокачки умений и оценку затара.
Сборка копируется в игру одной кнопкой (код `base64(zstd(protobuf))`).

Разделы:
- главная (рулетка);
- «Собрать команду» (`?team=`, `?squad=`);
- «Крутить билд» (`slots.html`, слот-машина со сборками игроков, редкости Trash…Legendary, лутбокс для пати). Сейчас в dev;
- «Мои рандомы» (`my.html`, журнал круток). Фаза 2, dev;
- **Аркады** (`/arcade/`): файтинг Bebop vs Lash в стиле 90-х. dev;
- скрытая лаборатория `/lab/builds.html` (сборки игроков, `noindex`, в коммерческий релиз не входит).

**Фаза 2 (цель dev):** вход через Steam, статистика игрока по сыгранным рандом-сборкам, таблица лидеров.
Сервер (VPS, Node + Postgres/SQLite, `api.randomlock.com`) ещё не куплен.

## 2. Ветки и окружения: главное правило

| Ветка | Сайт | Что это |
|---|---|---|
| `main` | https://randomlock.com/ | релиз, аналитика GA4, индексируется |
| `dev` | https://randomlock.com/dev/ | тест: метка DEV, без аналитики, `noindex`, ключи localStorage с префиксом `dev:` |

- **Работаем в `dev`.** В `main` не коммитим и не пушим без явной команды Алекса.
- Перенос `dev → main` делается только по команде Алекса. Перед этим `git fetch` и проверка, что `main` не ушёл вперёд:
  бот CI постоянно коммитит туда данные (`data: обновление из Deadlock API`).
- **Перед началом работы всегда:** `git fetch`, `git pull` в `dev`, и периодически `git merge origin/main`.
  После merge проверь `grep -n logTaken public/js/app.js`: в dev должны остаться функция и оба вызова.
- Общие места (`random.js`, `scoreBuild`, `normalize.js`, `sync.mjs`, формат `data/*.json`) лучше менять в `main`
  (по согласованию), потом подтягивать в `dev`.
- Перед каждым push: `node scripts/test.mjs` (+ `scripts/test-match.mjs`, `scripts/test-arcade.mjs`, если трогал эти части).
  **Тесты не ослаблять.** После push проверь, что CI (GitHub Actions) прошёл и /dev/ обновился.

## 3. Совместная работа с облачным Claude (claude.ai, проект «deadlock shuffle»)

Алекс работает в двух местах: здесь (локально, с плагинами) и в чатах проекта на claude.ai.
Переписку друг друга мы не видим. **Общая точка — этот репозиторий.** Поэтому:

- В конце каждой сессии обнови `docs/HANDOFF.md` и запушь его вместе с кодом.
- В начале сессии прочитай `docs/HANDOFF.md` и `git log --oneline -15`: там видно, что сделали в облаке.
- Не работать в одной ветке в двух местах одновременно. Закончил, запушил, потом переключаешься.

Шаблон `docs/HANDOFF.md`:
```markdown
# HANDOFF: последнее состояние работы
Обновлено: ДД.ММ.ГГГГ, где (локально / облако), ветка

## Сделано в последней сессии
-
## Не доделано / известные проблемы
-
## Следующий шаг
-
## Решения Алекса, которые надо помнить
-
```

Подробные документы (архитектура, план фазы 2, аркада, слот-режим) лежат в проекте claude.ai.
Если появится папка `docs/` с их копиями, читай их перед крупными изменениями.

## 4. Код

Статический сайт **без сборки**, ES-модули, всё в `public/`. Node 18+ нужен только для скриптов.

| Файл | Что делает |
|---|---|
| `public/index.html`, `js/app.js` | рулетка, i18n ru/en (`I18N`), крутка, анимации, «Скопировать в игру», команда |
| `js/random.js` | генерация: герой, предметы, порядок покупки, прокачка (`skillsFor`), оценка затара (`scoreBuild`, `MIX`), `PSEUDO`, `CURVE` |
| `js/normalize.js` | нормализация данных API, запреты, `itemScores`, `tuneHero`/`attachTune`, `heroMix`, `skillTune` |
| `js/buildcode.js` | код сборки для игры (байт-в-байт как эталон, не трогать без тестов) |
| `js/journal.js`, `js/match.js`, `my.html`, `js/my.js` | журнал круток и сопоставление матчей (фаза 2) |
| `slots.html`, `js/slots.js`, `css/slots.css` | режим «Крутить билд» |
| `arcade/` (`engine`, `fight`, `ai`, `anims`, `rigs`, `render`, `sound`, `input`, `hub`, `data`) | аркады |
| `js/tips.js` | карточки предметов как в игре |
| `js/theme.js`, `js/lang.js`, `js/env.js`, `js/config.js` | тема, язык, `IS_DEV`/`NS`, конфиг |
| `js/analytics.js` | GA4 + cookies (только main) |
| `lab/builds.html`, `js/lab.js`, `css/lab.css` | лаборатория |
| `public/data/*.json`, `public/icons/` | снимок данных, генерирует CI, руками не правим |
| `scripts/sync.mjs`, `watch.mjs` | синхронизация с Deadlock API (`https://api.deadlock-api.com/v1/*`) |
| `scripts/test*.mjs`, `calibrate*.mjs` | тесты и калибровка |
| `.github/workflows/sync.yml` | CI: синхронизация, тесты, деплой на GitHub Pages (main в корень, dev в `/dev/`) |

Команды: `npm test`, `npm run dev` (http://localhost:5173), `npm run sync`.

**При изменениях обязательно:**
- **CSP** в `<meta>` у HTML: новый внешний адрес добавить во все затронутые страницы. Встроенные `<script>` и `onclick=` запрещены.
- Данные из API выводить через `esc()`, числа через `num()`, ссылки через `safeUrl()`.
- localStorage только через `store` / ключи с `NS`, чтобы dev не портил main.
- Тексты интерфейса на RU и EN (лаборатория только RU).
- Аналитика: имена событий `social` (`target` = `yt|tw|tg`) и `donate` **не менять**, на них цели в GA4.

## 5. Решения, которые нельзя ломать

- Имена героев, предметов, умений **на английском**. Интерфейс по умолчанию RU (EN по языку браузера / выбору).
- Категории: **Оружие / Спиритизм / Живучесть**. Баланс инвеста: **Хаос / Поровну / Все в один**.
- Режим крутки: **Баланс рандом** (`curve`) / **Псевдо-рандом** (`pseudo`, по умолчанию) / **Полный рандом** (`chaos`).
- Псевдо- и баланс-рандом скрыто подкручены под героя (`tune.json`). **На сайте пользователям об этом не пишем.**
  Полный рандом не подкручивается (это проверяет тест).
- Ульта открывается только после трёх базовых умений. Тир 5 исключён (кроме спец-режима).
- Название сборки в игре: `RANDOMLOCK.COM - [оценка]% - [ДД.ММ.ГГГГ]`.
- Логотипы чужих брендов (YouTube, Twitch, Telegram) не рисуем: только названия и нейтральные значки.
- Дизайн: угольный `#100e0e`, текст `#f7e9d5`, акценты `#dd6638` / `#60cde3` / `#97da79` / `#ffe14d`;
  шрифты Alegreya 800 / Rubik 900 / Jost. Есть светлая тема.
