# HANDOFF: последнее состояние работы
Обновлено: 13.11.2026, локально (VS Code + Claude Code), ветка dev

## Сделано в последней сессии
- «Крутить билд»: автомат, лутбокс, символы барабанов и рубашка карт теперь нарисованные (вместо CSS).
  - Арт сгенерирован через Codex (gpt-6-astra, high) по промтам `slot_machine/prompts/`, выбран Алексом:
    корпус v1, рычаг v1, лутбокс v2, символы v2, рубашка v1. Исходники в `slot_machine/raw/` (не в git).
  - `slot_machine/cut.py` нарезает выбранные варианты в `public/img/slots/*.webp` (~530 КБ) и пишет замеры
    (окна барабанов, табло, рычаг, лампы, медальон сундука) в `slot_machine/layout.json`. Цифры из него захардкожены в `css/slots.css`.
  - Рычаг: нарисованный рычаг стёрт с корпуса, поверх стоит спрайт (кадры up/down в общей рамке).
  - Табло после крутки: «ГЕРОЙ 47.9%» цветом редкости (+ наклейка JACKPOT у Legendary), шрифт ужимается под длину имени.
    Корпус стоит по центру страницы, рычаг выступает вправо.
  - Лутбокс: смена кадра закрытый → открытый, отдельная летящая крышка не используется; число игроков в медальоне;
    после открытия кнопка «Открыть ещё»; сборка открывается и кнопкой «Сборка», и кликом по карточке.
  - Ссылка на пати: после открытия лутбокса кнопка «Ссылка на команду» копирует `slots.html?party=id.матчи.победы.игроки_…` (base36).
    Тиммейт видит те же карточки и редкости (статистика на момент открытия), забирает свою сборку «В игру»;
    кнопка у него «Открыть свой лутбокс» (убирает `?party=` и крутит новый, в настройки чужой размер пати не пишется).
  - Гарантия дропа в лутбоксе (`GUARANTEE` в `slots.js`): одна карточка не ниже 2–3 → Unique, 4–5 → Rare, 6 → Ultra Rare.
    Сначала ищется гарантированная (`rollLucky`, по кэшу пулов), остальные — обычной круткой без её героя; нет сборок такой
    редкости в пуле героев — гарантия на ступень ниже.
  - Рубашка карт собрана из частей рисунка (верх, низ, кромки, медальон, CSS-полосы), поэтому заполняет карту любой высоты.
- Главная, «Собрать команду»: кнопка «Крутить» (повёрнута, с тенью) наезжала на «Следующий игрок» — `margin-top` у `.btn-next`
  в `css/styles.css`. Баг есть и в main, уедет туда с переносом dev → main.
- Звук вынесен в `public/js/slots-sound.js` (устройство как в аркаде): новый синтез + таблица `FILES` для замены файлами.
  Новые звуки: вращение барабанов (у каждого барабана своя петля, при торможении замедляется и смолкает — слышно,
  сколько барабанов ещё крутится), тряска сундука (петля), монеты к джекпоту, колокольчики редкостей.

## Не доделано / известные проблемы
- Звуки пока только синтез. Алекс может прислать файлы (список слотов — в шапке `slots-sound.js`), класть в `public/snd/slots/`,
  требование: лицензия с коммерческим использованием (CC0 и т.п.), mp3/ogg, всё вместе до ~400 КБ.
- Пороги редкостей (Trash < 45 … Legendary 60+) Алекс ещё не подтверждал.
- Если арт корпуса поменяется: перезапустить `python -I slot_machine/cut.py` и перенести цифры из `layout.json` в `css/slots.css` и `BULBS` в `js/slots.js`.
